# 💼 JobSearch – Job Portal Web Application

**JobSearch** is a web-based job portal designed to connect employers with job seekers. Built using **HTML, CSS, JavaScript, PHP, and Bootstrap**, this platform enables employers to post jobs, review applicants, and manage candidate profiles, while job seekers can search and apply for jobs that match their preferences.

## 🚀 Features

### For Employers
- Post job listings with detailed information  
- View applicants for each job posting  
- Access and review applicant profiles  

### For Job Seekers
- Browse and search job listings  
- Filter jobs by **location**, **expected salary**, and **job type** (full-time, part-time, remote)  
- Apply directly through the portal  

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript, Bootstrap  
- **Backend:** PHP  
- **Database:** MySQL
